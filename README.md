# 🛒 বাজার দর | BazarDor

### 🌿 নিত্যপ্রয়োজনীয় পণ্যের বাজারদর, এখন এক নজরে!

**BazarDor** is a modern, user-friendly, and fully responsive web application designed to help people in Bangladesh stay informed about the prices of daily essential products.

The platform allows users to explore product prices, track daily price fluctuations, browse different categories, and compare market prices through a simple and interactive Bengali interface.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| ⚡ **Next.js** | Frontend framework and App Router |
| ⚛️ **React.js** | Interactive user interface |
| 🎨 **Tailwind CSS** | Modern and responsive styling |
| 💻 **JavaScript** | Application development |
| 🔐 **BetterAuth** | Secure user authentication |
| 🍃 **MongoDB** | Database management |
| 🌐 **REST API** | Dynamic product data fetching |

---

## ✨ Key Features

### 📈 1. Daily Market Price Tracking
View the latest prices of essential products and easily identify which products have increased or decreased in price with clear percentage indicators.

### 🛒 2. Interactive Product Browsing
Explore daily essential products through beautifully designed cards displaying product names, prices, units, and price changes.

### 🗂️ 3. Category Filtering & Price Sorting
Browse products by category and sort them by price, from low to high or high to low, for a more convenient shopping experience.

### 🔐 4. Secure User Authentication
Register and log in securely using email and password or social login. Authenticated users can access protected product details and manage their profiles.

### 📱 5. Fully Responsive Design
Enjoy a smooth and consistent browsing experience across mobile phones, tablets, laptops, and desktop devices.
